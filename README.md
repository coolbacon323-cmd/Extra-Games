# Extra Games

Extra Games is a Windows game-store and launcher project for discovering, publishing, buying, downloading and managing PC games.

## Download the Extra Games Launcher

### From the Extra Games website

1. Open the Extra Games website.
2. Open **Download Launcher** in the sidebar.
3. Click **Download .EXE**.
4. The installer downloads as:

`Extra-Games-Launcher-Setup.exe`

5. Open the installer.
6. Choose the installation folder.
7. Finish the installation.

The installer is a real Windows x64 installer generated by the project's Electron build.

### Install shortcuts

The Windows installer creates an **Extra Games Launcher** Start Menu shortcut. The current installer configuration also creates a desktop shortcut.

### Uninstall

Open **Windows Settings → Apps → Installed apps**, find **Extra Games Launcher**, and choose **Uninstall**.

You can also use the uninstall entry created by the Windows installer.

## Using the Launcher

After installation:

1. Start **Extra Games Launcher** from the Start Menu or desktop.
2. Use the sidebar to switch between:
   - **Home** — featured content and quick navigation.
   - **Library** — your game collection.
   - **Store** — games and store content.
   - **Community** — community features.
   - **Upload Game** — publish a game package.
   - **Account** — sign up, log in and log out.
   - **Download Launcher** — get the Windows installer again.
   - **Settings** — launcher settings.

## Create an account

1. Open **Account**.
2. Enter a display name, email address and password.
3. Click **Sign up**.
4. After registration, the launcher signs you in automatically.

To return later, use the **Log in** form with the same email and password.

## Upload a game

You must be signed in.

1. Open **Upload Game**.
2. Enter the game name.
3. Add a description.
4. Set the price in EUR.
5. Select the game package.
6. Supported package formats are **.ZIP** and **.EXE**.
7. Click **Upload Game**.

Uploaded games are stored with a **pending** approval status. The store should only expose games that have been approved.

## Buying games

1. Sign in to your Extra Games account.
2. Open the Store.
3. Choose a game with a configured purchase button.
4. Continue to Stripe Checkout.
5. Complete payment through Stripe.

### Stripe setup for the server

Payments require a Stripe secret key on the server. Do **not** put a Stripe secret key in browser code or commit real keys to GitHub.

Use environment variables such as:

```text
STRIPE_SECRET_KEY=sk_test_your_key_here
STRIPE_WEBHOOK_SECRET=whsec_your_webhook_secret_here
```

The repository contains `.env.example` as the starting point.

## Running Extra Games from source

### Requirements

- Windows
- Node.js 22 or newer
- npm

### Install dependencies

```bash
npm install
```

### Start the desktop launcher

```bash
npm start
```

The Electron launcher starts the local Extra Games web server automatically and opens the launcher at:

`http://127.0.0.1:3000`

### Start only the web server

```bash
npm run server
```

Then open:

`http://127.0.0.1:3000`

## Build the Windows installer yourself

```bash
npm install
npm run dist
```

The Windows installer is generated in the `release` directory using the filename:

`Extra-Games-Launcher-Setup.exe`

## Project layout

- `index.html` — launcher/site interface.
- `styles.css` — launcher styling.
- `app.js` — frontend navigation, account actions, uploads and checkout calls.
- `server.js` — local Express server, authentication and game upload APIs.
- `electron/main.js` — Electron desktop launcher entry point.
- `electron/updater.js` — Electron updater integration.
- `api/create-checkout-session.js` — Stripe Checkout session creation.
- `.github/workflows/windows-launcher.yml` — automated Windows installer build.
- `launcher/` — generated launcher installer files when the build workflow publishes them.

## Important notes

The project is actively being developed. Features such as the complete purchase-to-library flow, production-grade game storage, administrative approval tools and fully wired automatic launcher updates still require additional backend integration before this should be treated as a production marketplace.

Never commit:

- Stripe secret keys
- webhook secrets
- account passwords
- private credentials

For development, test Stripe with Stripe's test keys and test mode.
