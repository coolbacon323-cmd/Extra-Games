# Extra Games Launcher — Windows installation guide

## What you install

The Extra Games Launcher will be distributed as a Windows .exe installer.
Example: Extra-Games-Launcher-Setup.exe

## Installing the launcher

1. Download the latest Extra-Games-Launcher-Setup.exe release.
2. Open the downloaded .exe.
3. If Windows asks for confirmation, verify that the file came from the official Extra Games release before continuing.
4. Follow the installer steps.
5. Choose the installation folder, or keep the default.
6. Finish the installation.
7. Start Extra Games Launcher from the Start Menu or desktop shortcut.

## First launch

The launcher should open to the Extra Games home screen. Once it is connected to the Extra Games service, sign in with your Extra Games account.

The launcher should never require users to enter passwords into a random third-party installer.

## Updating

Future releases will use versioned installers such as:
- Extra-Games-Launcher-Setup-0.1.0.exe
- Extra-Games-Launcher-Setup-0.2.0.exe

The launcher checks GitHub Releases for newer versions and can download/install updates.

## Developer packaging

The repository already contains the Electron packaging layer and a stable application ID. GitHub Actions builds the Windows installer and publishes it as a release artifact.

Do not download or run an .exe generated by an untrusted source.

## Planned installer features

- Windows .exe installer
- Start Menu shortcut
- Optional desktop shortcut
- Uninstall support
- Launcher auto-update support
- Version display
- Secure connection to Extra Games
- Game installation and update management
